# Development Task Planner

Консольное приложение для ведения проектов и задач разработки. Проект продолжает сценарий ПР1: функции определения статуса, срочности и возможности назначения сохранены и встроены в полноценную систему работы с коллекциями и JSON-файлами.

## Возможности

- создание и просмотр проектов;
- создание задач с приоритетом и дедлайном;
- поиск задач по названию и описанию;
- назначение исполнителя с проверкой роли;
- изменение прогресса и автоматическое определение статуса;
- фильтрация по статусу и сортировка по срочности;
- генератор ближайших дедлайнов;
- статистика по задачам;
- автоматическая загрузка и сохранение данных в JSON;
- обработка некорректного ввода и ошибок файлов.

## Структура

```text
development-task-planner/
├── main.py              # меню и сценарий приложения
├── models.py            # TypedDict-модели данных
├── projects.py          # операции с проектами
├── tasks.py             # бизнес-логика задач
├── storage.py           # чтение и запись JSON
├── utils.py             # ввод и разбор дат
├── data/
│   ├── projects.json
│   └── tasks.json
├── tests/               # автоматические тесты pytest
├── requirements.txt
└── setup.cfg
```

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

## Проверка качества

```bash
pytest -q
flake8 .
```

## Формат данных

Проекты хранятся в `data/projects.json`, задачи — в `data/tasks.json`. Даты записываются в ISO-формате `ГГГГ-ММ-ДД`. Статус и срочность вычисляются при работе программы и не дублируются в файлах.

## Развитие проекта

На следующем этапе словари задач и проектов могут быть заменены классами, а консольный интерфейс — веб-приложением на Django с PostgreSQL и REST API.
