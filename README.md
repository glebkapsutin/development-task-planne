# Система планирования задач разработки (Task Planner)

## Назначение
Веб-приложение для управления проектами, постановки задач, отслеживания их статусов и контроля прогресса разработки.

## Целевая аудитория
Менеджеры проектов (Project Managers), тимлиды, разработчики и тестировщики в IT-компаниях.

## Предметная область
Управление разработкой программного обеспечения, планирование спринтов, трекинг задач (Task Tracking).

## Основные сущности
- Проект (Project)
- Задача (Task)
- Пользователь (User)
- Статус задачи (Status)

## Основные функции
- Создание, редактирование и удаление задач с указанием приоритета и дедлайна.
- Назначение задач на конкретных исполнителей и распределение по проектам.
- Отслеживание прогресса: изменение статусов задач (Новая, В работе, На проверке, Завершена).

## План развития
На следующих этапах планируется:
- разработка веб-приложения на Django;
- подключение базы данных (PostgreSQL);
- реализация системы пользователей (регистрация, роли);
- разработка REST API;
- контейнеризация приложения (Docker);
- настройка CI/CD.
